# Contributing

Found a tool that belongs here? Great. A few ground rules:

1. One line per tool: `[Name](link) - what it does, plainly.`
2. No marketing copy. Say what it is and who it is for.
3. Prefer open source. Closed-source tools are fine if they have a real free tier.
4. No dead links. CI checks every link on every PR and weekly; PRs with dead links will not merge.
5. Put it in the right section. If none fits, propose a new one in the PR.

## Adding a tool

Edit `README.md`, add your entry under the right heading, and open a PR.
Keep descriptions to one line. If you are affiliated with the tool, add
"(Author-affiliated.)" to the README entry itself and say so in the PR description too.
